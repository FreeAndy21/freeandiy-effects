FreeANDIY Effects portable mode

While this file sits next to freeandiy-effects.exe, FreeANDIY Effects keeps its settings, keyboard shortcuts,
crash-recovery files, logs and plug-ins in the EffectCraftData folder beside it instead of
%APPDATA%\FreeANDIY Effects. Copy the whole folder to move FreeANDIY Effects with its settings.

The disk cache, media cache and conformed audio still go to %LOCALAPPDATA%\FreeANDIY Effects unless
you choose other folders in Edit > Preferences > Disk.

Delete this file to use the normal per-user settings folder (%APPDATA%\FreeANDIY Effects) instead.
If EffectCraftData can't be written (for example on a read-only drive), FreeANDIY Effects logs a
warning and uses %APPDATA%\FreeANDIY Effects instead.
